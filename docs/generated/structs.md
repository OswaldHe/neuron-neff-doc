# Instruction struct layouts

Generated by `tools/gen_reference.py` from the vendor accessors in neuron-dbg (`tools/isa_layout.py`) plus the supplement. One row per leaf field in wire order. *bits* is `shift/mask` for bitfields; *n* is the array length (elements `stride` bytes apart). Fields at the same offset are union members: the marker byte or an `*_src` field says which one applies.
